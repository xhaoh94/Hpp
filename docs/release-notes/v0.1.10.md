# Hpp v0.1.10 发布说明

> 发布日期：2026-11-16
> 包含：Windows / Android / Linux（由 CI 在发布后自动构建）

## 本次版本主要改动

### Git 工作台

- 工作台从「状态 + 暂存 + diff + 提交 + stash」扩展为完整的本地 Git 操作面板：
  - 提交历史与提交详情，单文件历史和逐行追溯（blame，长文件虚拟滚动）。
  - 本地分支的创建、切换、合并、删除和发起 rebase；rebase 冲突可在弹窗里继续、跳过或中止。
  - worktree 列表与安全删除；fetch / pull --ff-only / push。
  - 文件级冲突解决（当前版本 / 对方版本 / 打开文件 / 标记已解决），以及继续或中止 merge、rebase、cherry-pick、revert。
  - 会话内 Git 操作日志，记录执行的命令与结果。
- 文件、hunk 级暂存 / 取消暂存 / 丢弃；丢弃前确认。
- 独立 worktree 主工作区脏时，新建会话弹窗提供「打开 Git 工作台」入口，处理后自动重新检测。

### 会话与用量

- 会话历史支持全文搜索、导出 Markdown，并生成交接摘要供新会话接续。
- 聊天底部显示 token 用量，按模型分组统计输入、缓存命中与输出，可查看详情。
- 新建会话弹窗重做，支持引用与参数选择。

### Linux、Wayland 与全局唤起

- 全局唤起按运行环境自动识别合成器：Hyprland 写 `hpp-quick-ask.conf` 并 `hyprctl reload`，sway 写 `hpp-quick-ask.conf` 并 `swaymsg reload`，niri 写 `hpp-quick-ask.kdl` 并重载。
- KDE / GNOME Wayland 没有可写的纯文本配置，注册失败时设置页给出手动绑定指引。
- niri 窗口规则与浮动行为修正，输入条不会被平铺进滚动列；Wayland 下窗口内唤出输入条做了兜底。

### 编辑器集成与产物

- 编辑器桥接扩展更新：发送选区、当前行、当前文件与多选文件 / 文件夹，未保存与远程文件携带字面内容。
- 本轮产物去重改用结尾匹配：同一文件一次记相对路径、一次记绝对路径时不再重复出现。

### 稳定性

- 移除误提交的 Windows 绝对路径测试日志：此前 `git add -A` 把测试落到工作区的 `C:\temp\...` 目录一并提交，导致 Windows 上 `git pull` 报 `invalid path`。历史提交未改写，仅在最新树中删除这些路径。
