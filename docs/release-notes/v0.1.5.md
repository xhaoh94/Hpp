# Hpp 0.1.5 发布说明

## 本次版本主要改动

### 对话展示等级（简洁 / 标准 / 详细）
- 新增「输出内容」等级设置（位于设置 → 通用设置 → 应用行为）：
  - **简洁**：隐藏运行命令、查看文件、修改文件这些操作细节，思考、正文、问卷、错误、状态、子 Agent 全部保留。
  - **标准**：把命令、查看文件、修改文件合并成一条摘要；点击摘要可展开，按「已运行 N 条命令 / 已修改 文件 / 已查看 文件」逐行列出，文件名可点击打开。
  - **详细**：完整列出每一步操作与变更文件。
- 消息底部的变更文件面板（文件列表 + 审核入口）在三个等级下都完整显示，不再被等级隐藏。
- 底部任务胶囊的变更数量在三个等级下都显示。

### 审核与差异查看
- 审核弹窗首次打开直接定位到第一个改动处：行集合稳定后才定位，避免「先显示文件顶部、过一会儿再跳」。
- 变更点整体居中；变更块本身高过视口时改为对齐顶部，保证能看到改动起点。
- 「上一个 / 下一个改动」改为直接跳转，不再播放滚动动画。
- diff 文件在聊天里的预览从「悬停弹出」改为「点击展开」：点击文件行就地展开 diff 面板，面板宽度随窗口自适应（最大 1120px），可在面板里打开完整文件。
- 聊天里的文件路径支持点击打开预览；带行号的引用（`README.md:242`）会自动去掉行号；文件不存在时给出带完整路径的提示。

### 会话与通知
- 新建会话时模型列表与后端初始化并行加载，模型名不再空等约 1 秒。
- 新建会话在后端初始化期间显示转圈占位，而不是「发送消息开始对话」却发不出去。
- 会话启动过程新增分阶段计时日志，落盘到 `hpp-data/logs/hpp-timing.log`，便于排查启动偏慢的环境。
- 任务完成通知改为回显用户最后一条消息（不再是 Agent 的回复），并对 Markdown 做纯文本降级。
- 会话标题、页签、历史列表在只带附件时显示具体名字（`[shot.png]` / `[a.ts]` / `[src]`），不再是空白或笼统的「[图片]」。

### 移动端
- 修复桌面端修改「输出内容」等级后手机端不生效的问题。
- 修复思考条目在正文前后的合并顺序错乱。
- 标准档的操作摘要、折叠行数量、任务胶囊与桌面端保持一致。

### 构建与稳定性
- 修复 Windows 上 `electron-builder` 因包管理器路径含空格导致 `No JSON content found in output` 的打包失败（新增幂等的 postinstall 补丁）。
- 移除启动会话时的 shell `echo` 预检，改为零进程的静态判定，避免个别环境被拖慢数秒。

## 升级提示
- 桌面端通过内置更新检查获取新版本。
- 本次未重新构建 Android 安装包（当前构建环境缺少 Android 工具链），移动端改动将在下一次 Android 构建中生效。
