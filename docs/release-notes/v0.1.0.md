# Hpp v0.1.0 发布说明

## 本次版本主要改动

### 🎨 代码块样式重构
- 修复代码块文字横向滚动时贴边框问题，底部和右侧增加安全间距
- 重构代码块结构：引入 header 行（语言标签 + 复制按钮）和 scroll-wrapper 滚动容器，彻底解决 padding 被滚动容器"吞掉"的问题
- 语言标签从绝对定位改为行内显示，不再与代码内容重叠
- 缩小代码块上下空白区域，视觉更紧凑
- Web/移动端代码块同步桌面端样式，并隐藏滚动条（保留滚动功能）

### 📱 返回按钮导航修复
- 修复移动端/APK 聊天界面点击返回按钮直接跳转首页的问题
- 正确返回流程：聊天界面 → 会话列表 → 首页

### 🔄 发布流程自动化
- 新增 `release-all.cjs` 一键发布脚本，支持构建、归档、上传全流程
- 新增 `reset-github-release.cjs`，改为增量更新模式而非删除重建，避免资产丢失
- 发布说明改为从 `docs/release-notes/v<版本号>.md` 读取，强制校验防止复用旧内容
- 更新发布文档 `docs/release.md`

### 🛠 其他改进
- Editor 状态（模式/标签页/活动 tab）持久化到数据存储
- 修复开发模式下 Electron 加载旧静态构建产物的缓存问题
- 移动端样式与桌面端同步更新
