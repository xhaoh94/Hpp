# Hpp v0.1.1 发布说明

> 发布日期：2026-08-25
> 包含：Windows / Android / Linux（Linux 由 GitHub Actions 构建）

## 本次版本主要改动

### 🤖 统一 Subagent 能力
- OpenCode、Claude、Droid、Codex 和 Pi 统一接入 subagent 生命周期事件、状态展示、权限关联、提问转发、超时和中止处理。
- Pi 增加内置 `scout`、`planner`、`reviewer`、`worker` profile，支持并行任务、串行 chain、`{previous}` 结果传递、独立模型和结构化摘要。
- 第三方 Pi Extension 改为通过受控 manifest 和 capability 配置加载，避免任意扩展自动进入 subagent 上下文。

### ✅ Todo 与计划同步
- 支持将 Pi Todo Extension 返回的 `details.tasks` 转换为 Hpp 原生 Todo/Plan 展示。
- 修复 Todo 列表只显示当前任务步骤，避免把整个历史会话快照重复显示。
- 同步桌面端与移动端 Todo 的运行状态和动画表现。

### 🔌 Pi 扩展支持
- 支持 `@ff-labs/pi-fff@0.10.5`，提供 `fffind`、`ffgrep` 等代码检索工具。
- 支持 `@juicesharp/rpiv-todo@2.7.1`，提供 `todo` 工具和 `/todos` 命令。

### 🖥️ 桌面与编辑器
- 资源管理器可以同步外部文件变动，已打开文件也会同步刷新。
- 桌面端新建会话改为弹窗交互。
- 优化编辑器搜索，优先匹配当前位置附近的结果。
- 优化移动端正文输出样式。
