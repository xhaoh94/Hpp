# Hpp v0.1.12 发布说明

> 发布日期：2026-11-20
> 包含：Windows / Android / Linux（由 CI 在发布后自动构建）

## 本次版本主要改动

### 渠道配置同步（服务器）

- Agent 配置标题栏新增「同步」入口：可添加多台渠道配置服务器（地址 + SSH 账号 + 服务端口），把极小的同步服务部署到服务器 / NAS，再手动备份 / 拉取渠道配置。
- 添加服务器时「测试连接」会显示主机指纹、Docker 版本、sudo 是否可用、容器状态；确认后「保存并部署」通过 SSH 上传服务文件、生成 Token、启动容器，并用 `/health` 验证。重复部署幂等，容器重建但历史备份保留。
- 状态检测区分「未部署 / 已部署未运行 / 运行中 / 无 Docker / 无 sudo / 不可达」。备份上传前显示 Agent / 渠道数量并确认；拉取走与导入 JSON 相同的冲突界面（覆盖 / 跳过 / 另存），确认后才写本地配置。不做后台自动同步，点一次才发一次请求。
- 渠道配置支持导出 / 导入 JSON。
- 安全：连接信息存 `hpp-data/channel-sync.json`（权限 0600），SSH 密码与 Token 用 `safeStorage` 加密落盘，界面只显示掩码；首次连接记录 SSH 主机指纹，指纹变化即中止。同步包里的 API Key 为明文，服务只应暴露在组网 / 内网。
- 服务端是零依赖 Node 单文件（`docker/channel-sync`），只监听一个端口，快照与最近 20 份历史存在容器 `/data` 卷。

### Linux 安装

- 新增一行命令安装：`curl -fsSL https://raw.githubusercontent.com/xhaoh94/Hpp/main/scripts/install-linux.sh | bash`。自动取最新版本、建桌面入口、装运行依赖；仍可从 Releases 下载 AppImage。

### 插件与后端

- 移除 droid 插件及其后端（插件目录不再提供 droid）。其余插件版本不变：claude 1.0.4 / pi 1.4.1 / opencode 1.4.3 / codex 1.1.3。

### 构建与发布

- 发布改为全平台云端构建：Windows / Android / Linux 三个 GitHub Actions workflow，本机只创建 Release 与触发；大文件不再从本机上传。
- Android 云端构建从仓库 Secrets 还原发布签名密钥，签名与历史版本一致，老用户可覆盖升级。
- 发布手册 `docs/release.md` 同步更新。

### 命令描述

- 命令条目的兜底描述改为项目感知：不再只说「检索内容 / 列出目录」，而是按命令与目标给出「搜索项目代码 / 列出项目文件 / 查看 Git 工作区状态 / 运行项目脚本」等更具体的文案。
- 新增一批 PowerShell 命令（Get-ChildItem / Get-Content / Select-String / New-Item 等）的中文描述。
- 保留「已运行 X」的完成时语义：模型写的描述原样显示，自动推断的描述由展示层补时态，不会退化成裸「执行 X」。

### 其他修复

- 设置页、Diff 悬浮预览、会话模型切换等多处细节修正。
