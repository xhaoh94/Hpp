# Hpp v0.1.6 发布说明

## 本次版本主要改动

- 修复代码块里点击文件路径无法打开的问题：模型给出的相对路径（如 `Hotfix/Modules/...`，相对 Unity 代码根而非仓库根）直接解析失败时，改为按相对路径后缀在项目树中递归兜底查找第一个命中文件，命中即用真实路径打开/定位。
- 新增主进程 `fs:findProjectFile` IPC（按路径后缀递归搜索，跳过 node_modules/.git/Library/obj/bin/.vs/dist/out/target/build，深度上限 12），渲染层 `handleOpenFile` 在直接解析 miss 时兜底调用。

## 说明

- 本版本基于 v0.1.5，仅修复上述文件打开路径解析问题，无其他功能变更。
