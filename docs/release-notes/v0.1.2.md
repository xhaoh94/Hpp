# Hpp v0.1.2 发布说明

> 发布日期：2026-09-12
> 包含：Windows / Android / Linux（Linux 由 GitHub Actions 构建）

## 本次版本主要改动

### ✂️ 局部文件内容撤销
- 新增审核弹窗的 **hunk 级局部撤销**：可精确回退某一段 AI 改动，而不必整文件还原。
- 撤销走真实 `git apply -R` 还原，撤销前的文件快照备份在用户数据目录，可安全回滚。
- **修复 CRLF（Windows 行尾）文件撤销始终失败**：此前生成补丁时会把行尾 `\r` 归一化掉，而 `git apply` 逐字节匹配上下文行，导致正反两个方向统一报 `patch does not apply`；现在补丁按原始字节生成。
- 修复同一文件多次编辑后补丁堆积，改为按文件保留最新一份累计快照，避免过期补丁干扰撤销判定。

### 🤖 Agent 渠道与模型
- **修复渠道弹窗新增或修改模型后立即切换报错** `Model switch failed: Pi model is not available`：worker 的模型注册表此前只在会话初始化时构建一次且不监听配置文件变化，现在切换前会重新读取磁盘配置再判定可用性（纯本地，不发网络请求）。
- **上下文压缩新增「启用上下文压缩」开关**，可彻底关闭自动压缩；关闭后上下文超限时会话将直接报错，弹窗内已明确提示该代价。
- **压缩模型支持直接从已配置渠道中选择**（与 SubAgent 一致的 `provider/model` 选择器），渠道被删除时自动回退当前模型；原有的自定义 OpenAI 兼容模型入口（Base URL / API Key / 协议）保留给未声明该能力的插件。

### 💬 会话与交互
- 修复带富文本（composer 文档）的发言「显示更多」折叠失效。
- 修复 `@文件` 会清空已输入文本的问题。
- 修复输出过程中无法滚动查看历史消息。
- 会话页签悬浮时显示完整首条内容。
- 任务面板宽度自适应。
- 空闲会话运行时自动释放优化。

### 🖥️ 桌面与插件稳定性
- 插件进程生命周期与注册表加载稳定性优化，避免插件宿主被并发重载误杀。
- 远程桥接与数据持久化优化，提升移动端连接桌面端时的同步可靠性。
- 桌面字体显示优化（12px→14px，14px→15px）。
- 修复 subagent 超时时间过短导致任务被提前中断。
