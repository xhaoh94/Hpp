# Hpp v0.1.7 发布说明

> 发布日期：2026-11-09
> 包含：Windows / Android / Linux（由 CI 在发布后构建）

## 本次版本主要改动

### 编辑器集成

- 新增 Zed 编辑器接入（合并 `tasks.json`、按需生成 keymap，复用 Hpp 自带 Node 运行时，无需额外安装 Node）；设置面板只列出已安装的编辑器，未安装项收到底部折叠区，并修复下拉菜单被滚动容器裁切的问题。
- VSCode 扩展新增「发送文件夹」右键命令，编辑器侧 CLI 与 Zed 同步支持 `--folder`。
- 修复部分电脑安装 VSCode 插件失败：`where code` 优先返回无扩展名垫片导致 `ENOENT`，以及 Windows 上 `.cmd` 被直接 `execFile` 执行导致 `EINVAL`；现在按平台正确选择 `.exe` / cmd 包装，错误信息带上具体命令路径。

### 精简内置编辑器与设置

- 移除 Hpp 自带编辑器模式与项目内全文搜索（`Ctrl+Shift+F`），文件打开统一走预览弹窗，代码定位交给外部编辑器。删除约 24 个文件、1.8 万行代码与 15 个编辑器相关依赖，主包体积明显下降。
- 通用设置移除「工作区」，默认工作区只在项目卡片上修改；新增内置默认工作区，路径以设置为唯一真源。
- 移除 pi 上下文压缩模型配置与压缩按钮，压缩统一走 pi 自身默认逻辑。
- 移除 codemode / tool_search 用户开关、对应弹窗，以及 MCP 弹窗里的「自动启用 Codemode」勾选；开启 MCP 时由 Hpp 自动挂载所需扩展。
- 移除插件列表中恒定显示的 Plan 徽章。
- MCP 配置写回只覆盖 `mcpServers`，保留 pi `mcp.json` 的其它顶层字段；新增公共 JSONC 解析，兼容注释、尾逗号与 BOM，修复读取用户配置时的 JSON 报错。

### 聊天体验

- AI 回复的复制、fork、时间、模型操作区改为常驻显示；用户自己消息的悬停逻辑保持不变。
- 新增 `Ctrl+Alt+Enter`：当前对话仍在运行时，把输入框消息插到待发送区首位并自动触发引导，注入当前回合；空闲时等同普通发送。
- 长文本粘贴（超过 1000 字符或 10 行）在输入框里折叠成一枚标签，带行数/大小、悬停或点击预览全文、复制全文、另存为 txt；超过 20 万字符的粘贴直接拒绝并提示。原文完整发送给 Agent，编辑回填、复制与内容判定都按完整文档处理。
- 用户发言里的代码（``` 围栏或整段明确是代码）改用代码块渲染，带语言标签、语法高亮、复制与运行；其余正文仍按纯文本展示，不走 Markdown，避免 `#`、`*` 把原话改掉。粘贴来的代码展示前按花括号层级重排行首缩进，只影响显示。
- 上述两项同步到远程/手机端：远程协议新增 `paste` 节点，手机端消息气泡按代码块展示，复制改为取完整文档文本。

### 插件与运行时

- 插件版本与卸载统一收到 Agent 列表，官方插件弹窗只负责安装与更新。
- CLI agent 优先使用自带升级命令，不再强依赖 npm 全局写入；修复「退出码为 0 但实际失败」被误报为成功的问题。
- 修复内置模型判定失效与竞态、能力回写 `models.json` 后 UI 与运行时不一致，以及插件更新被静默丢失的问题。
- 子 Agent 的成败判定改为同时看 `stopReason` / `errorMessage`（pi 的 json/rpc 模式在上游报错时仍会返回 0），可重试的上游错误带抖动自动重跑，并行汇总按任务数均分输出预算。
- Pi SDK 离线安装包构建改为自动获取 npm 上的最新稳定版本，查询失败直接中止而不是静默打旧包。
- 修复 Pi SDK 升级后的依赖树残留：旧版 shrinkwrap 会把 `pi-ai` 嵌在 `pi-coding-agent/node_modules` 下，覆盖安装留下旧副本，新版代码 `import` 新文件时报 `ERR_MODULE_NOT_FOUND`，表现为主会话正常、子 Agent 全部启动失败。现在升级前整棵重装依赖树，并在状态检测里主动报告这类混合依赖树；子 Agent 优先走预打包 CLI，绕开模块树解析。
- 修复编辑器 CLI 路径相关测试在 Linux CI 上因平台判断导致的误报（补齐可注入的 platform 参数）。
