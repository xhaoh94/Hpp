# Hpp v0.1.8 发布说明

> 发布日期：2026-11-11
> 包含：Windows / Android / Linux（由 CI 在发布后构建）

## 本次版本主要改动

### 手机端外观

- 新增浅色 / 深色 / 跟随系统三档外观，在连接页与聊天页的「外观」按钮里切换；跟随系统会监听系统外观变化实时更新。
- 首屏在 WebView 绘制第一帧前就定好主题并同步状态栏颜色，避免启动时先闪一下深色再跳到浅色。
- 深色变量全部补齐浅色对应值，界面里写死的主题敏感颜色改为引用变量，代码块、消息气泡、弹层、输入框在浅色下都保持可读。
- 修复浅色下代码块复制按钮白字看不清的问题。

### 手机端更新下载

- 更新下载可切到系统后台进行：切后台后不再弹回更新弹窗、也不会自动安装，下载期间可继续使用 Hpp。
- 后台下载时在右下角显示进度胶囊（含百分比），点它可重新打开更新弹窗；下载完成或失败会更新胶囊文案与状态。
- Android 侧下载完成通知改为可见，标题与描述提示这是后台下载结果。

### 代码审核与 diff 面板

- 审核面板左侧文件列表只显示文件名，不再显示整条路径；存在同名文件时那几项自动退回项目相对路径，完整路径仍在悬停提示里。
- 文件栏宽度按最长文件名与增删统计的实际像素自动撑开（上限放宽到 560px），手动拖拽或用方向键调整过之后不再自动改写。
- 点击聊天里 diff 文件行弹出的小 diff 窗口改为按视口宽度铺开、可盖在侧边栏上，四周留 12px 边距并保留圆角与投影；高度仍沿用原来的 64vh，垂直位置贴着所点文件行。
- 该窗口补了 header 关闭按钮（宽度铺开后原文件行会被盖住），Esc、点外部、窗口尺寸变化关闭逻辑不变。

### 桌面端外观

- 修复浅色主题下「运行中」盲文点阵几乎看不见的问题：点阵改用强调色、略微放大并加柔光。会话列表行、聊天头部、Agent 检查加载行三处一并生效；深色主题保持原样。

### 构建与 CI

- 修正长文本粘贴标签一处非法 CSS 值（`margin: 2px 0x`），并调整标签在气泡内的高度与对齐。
- 开发服务器开启 HMR。
- Linux AppImage 构建跳过插件内容指纹的跨平台校验：指纹按原始字节计算，Windows 工作区的 CRLF 与仓库 LF 不一致会让 Linux checkout 后必然误判；发布侧打包时仍会正常校验。

## 本次插件版本
