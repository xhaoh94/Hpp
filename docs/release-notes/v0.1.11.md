# Hpp v0.1.11 发布说明

> 发布日期：2026-11-18
> 包含：Windows / Android / Linux（由 CI 在发布后自动构建）

## 本次版本主要改动

### 子 Agent 体验

- 子任务支持极简标题：调度 Agent 为每个子任务指定 2~6 字的简短标题（pi 走 `subagent` 工具的 `title` 参数，claude 走 Task 工具的 `description`），聊天区胶囊与监视窗页签优先显示它，不再用整句任务描述撑满。
- 监视窗重新设计：面板恢复动态高度、各内容块固定单行，消除内容实时刷新时的抖动；页签自动换行、一屏看全所有子任务，去掉页签运行时间；已完成任务圆点变绿。
- 「活动」固定单行显示最新进展；灰底输出默认单行、点击展开 Markdown 全文（标题 / 列表 / 行内代码正常渲染），再点收起。
- 修复 pi 子任务标题在中段映射丢失的问题，以及 claude 子任务完全没有标题通道的问题。

### 命令与文件展示

- 标准档操作摘要展开后，claude 的命令与 pi 一样逐条显示「终端图标 + 模型写的意图」，不再只显示「已运行 N 条命令」。
- 修复 claude 流式事件里命令意图描述在结束阶段被丢弃的问题。

### 会话与界面

- 新建会话弹窗点击「创建会话」立即关闭，会话页签出现即可见，不再等待 Agent 后端启动；启动失败改为全局提示。
- 空会话底部状态栏显示固定文案「暂无统计数据」，不再留空或显示无效的 0% 统计（桌面与手机一致）。
- 去掉子 Agent 详情区的空白占位与不自然的高度跳变，长输出不再挤掉「最后活动」。

### Git 工作台与设置

- Git 工作台多项交互与界面优化（变更 / 待提交操作、右键菜单、错误提示、hunk 按钮统一术语：储藏 = stash，加入「待提交」= stage）。
- 设置页与上下文用量弹窗的细节调整。

## 插件版本

- Pi 插件 1.4.1：新增子任务 `title` 参数与界面标题透传。
- Claude 插件 1.0.4：支持子任务极简标题，随描述一并上报。
- 其余插件随包发布（codex 1.1.3 / opencode 1.4.3 / droid 1.3.8）。

## 修复

- 会话导出测试按本地时间构造输入，兼容 CI 的 UTC 时区。
