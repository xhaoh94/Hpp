# Hpp v0.1.9 发布说明

> 发布日期：2026-11-13
> 包含：Windows / Android / Linux（由 CI 在发布后自动构建）

## 本次版本主要改动

### 本轮产物：由模型显式声明

- 新增 `present_files` 工具：模型把这一轮真正交付给用户的成品（报告、表格、文档、网页、图片、安装包等）显式列出来，宿主按它渲染「本轮产物」清单，图片带缩略图、点一下直接打开。
- 显式声明优先于原来的写盘推断：只要模型调用了这个工具，中间脚本、日志、缓存里那些同名同扩展名的文件就不会再混进产物列表。
- 推断链路同步收紧（模型没调用时仍走这条）：系统临时目录（`%TEMP%`、`/tmp`、`/private/var/folders` 等）、依赖与缓存目录（`node_modules`、`.git`、`__pycache__`、`.next`、`coverage` 等）、以及工作区根下的 `tmp` / `.tmp` 草稿区一律不算产物。
- 补上 `doc` / `xls` / `ppt` 老格式；文件被删除时不再记为「产出」。
- 处理过程里这类工具调用显示为「正在呈现 N 个产物 / 已呈现 N 个产物」。

## 自 v0.1.8 起的累积改动

> v0.1.8 曾两次以同版本号覆盖重发，下面这些改动只存在于最新的 0.1.8 包与 0.1.9；仍在使用较早 0.1.8 安装包的会在此次升级中一并拿到。

### 子 Agent

- 修复「已完成却显示进度 1/2」：早期占位子任务（id 是裸工具调用 id）不再生成、不再累积；条目已结束时仍停在运行中的子任务不再计入进度分母，也不再在监视窗里占一个永远空白的页签。历史会话里的残留项直接从视图过滤，不需要清理数据。
- 增量事件不再抹掉已收到的输出：只带状态的更新不会清掉消息、实时输出与开始时间；`pending` 也不会把已运行或已结束的任务打回去。
- 子 Agent 运行中只在底部悬浮胶囊显示，全部结束后聊天区才出现这一行；聊天区胶囊去掉单个任务的运行时间，右侧「已运行 xxx」保留，悬浮胶囊的时间不变。
- 底部悬浮区恢复竖排（Subagent 胶囊 → Todo 胶囊 → 回到底部），「已运行 xxx」紧跟胶囊，不再被推到行尾。

### 快捷键

- 「发送消息」设置改为选择哪个键是普通发送、哪个键是引导发送：默认 Enter 普通发送 / Ctrl+Enter 引导发送，可对调；原来固定的 Ctrl+Alt+Enter 已移除。
- Shift+Enter 固定换行；输入框提示与设置摘要跟随所选模式。
- 引导发送 = 会话运行中把消息插到待发送区首位并立即引导，空闲时等价普通发送。

### 编辑器集成

- 修复「VSCode 发送到 Hpp 后打字仍进 VSCode」：Windows 的前台锁会拒绝后台进程抢焦点，`focus()` 只能把窗口提到视觉最前。现在插入前先置前窗口，再由原生调用（`SwitchToThisWindow`，失败时 `AttachThreadInput` + `SetForegroundWindow`）真正拿回键盘焦点，发送完可以直接在 Hpp 里打字。编辑器插件无需更新。

### 处理过程与输入框

- 命令条目补齐中文意图说明；「简洁」档位把思考与正文各自合并成一段，子 Agent 正文不显示、进度只留悬浮胶囊。
- 修复处理块多余分号被当文本渲染、详细档标题双层叠加、命令详情重复渲染表头。
- 浅色主题下思考扫光改为灰阶高亮；输入框关闭拼写检查，英文技术词不再被画红波浪线；粘贴进来的富文本格式统一归零，输入框不再偶发整段变粗。

### 代码审核与 diff 面板

- 审核面板左侧文件列表只显示文件名，同名文件才退回相对路径；文件栏宽度按最长文件名与实际增删统计自动撑开（上限 560px），手动拖过之后不再自动改写。
- 聊天里点击 diff 文件行弹出的小窗口改为铺满视口宽度、可盖住侧边栏，四周留 12px 并保留圆角投影，补了 header 关闭按钮。

### 桌面端外观

- 修复浅色主题下「运行中」盲文点阵几乎看不见（对比度不到 1.3:1）：改用强调色、略微放大并加柔光；深色主题保持原样。
