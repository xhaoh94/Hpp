# Hpp v0.1.15 发布说明

> 发布日期：2026-08-19
> 包含：Windows NSIS 安装包（x64）、Android APK（Release 签名）
> Linux AppImage：单独构建后放入 release 目录再发布

## 本次版本主要改动

### 移动端（Android APK）

- **修复返回按钮导航逻辑**：聊天内容界面按系统返回键现在先回到会话选择界面，再次按返回才会离开主机回到首页。此前会在聊天界面直接退到首页。
- **代码块显示优化**：同步桌面端的代码块样式，左右边距一致（Chromium 横向滚动不再"吃掉"边距）；语言标签放入独立 header 行，避免和代码首行重叠；上下留白缩小；Web 端不再显示横向滚动条。
- **Capacitor 返回键稳定性改进**：使用 ref 模式注册 backButton 监听器，避免因 React 依赖变化导致监听器被意外移除或复用。

### 桌面端（Windows）

- **新增文件全局搜索**：支持在当前工程范围内按文件名/路径模糊搜索并快速跳转定位。
- **新增代码审核窗口**：对模型输出的 Patch/Diff 提供集中审核视图，支持逐块查看、跳转和应用。
- **新增编辑器模式（EditorArea）**：在聊天外提供可独立操作的代码编辑视图，方便临时修改和对照。
- **代码块显示与语法高亮**：
  - 代码块超出宽度时改为在块内横向滚动，不再挤压整体布局。
  - 新增 C#、Lua 语法高亮，并替换为更接近 VSCode 的配色方案。
- **修复收缩状态弹窗显示不全**：Sidebar/窗口收缩模式下对话框和弹层宽度不再被裁剪，审核窗口跳转行为修复。
- **最新版 Electron 升级（含 Linux 输入法修复）**：整体运行在更新的 Electron 运行时上，同步修复 Linux 输入法等相关问题。

### 通用

- Agent CLI/SDK 版本管理、历史版本安装与一键回退已在 v0.1.14 基础上继续完善；若此前版本已正常使用可直接升级，无需额外迁移。
- 发布流程加入强制校验：发布脚本会读取本目录下对应版本的说明文件，缺失或仍含占位内容时会拒绝发布，避免复用旧版本说明。
