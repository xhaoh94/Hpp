# Hpp 0.1.4 发布说明

> 桌面端（Windows / Linux）与移动端（Android）同步发布。

## 本次版本主要改动

### 性能与稳定性
- 远程桥接增加客户端存在性门控：当无远程客户端连接时跳过流式 upsert，只保留回合边界 replace，修复隔夜 AI 任务后界面卡顿与渲染进程内存过高的问题。
- DiffBlock 撤销状态增加缓存（TTL 120s，带在途去重与失败不缓存），修复会话挂载时滚动卡顿。

### 消息与附件
- 图片发送按 magic number 识别真实格式，识别不了的不发送；SVG / BMP / AVIF / ICO 在附件阶段光栅化为 PNG，修复 tanwan 等渠道「unsupported image」400 错误。
- 新增本地媒体服务、媒体预览、粘贴附件、文件右键菜单、视频缩略图、会话标题等能力。

### 编辑器体验
- 代码块：html / svg 等可运行代码块右上角新增「运行」按钮，本地浏览器查看效果。
- 超链接：右键菜单支持「打开所在文件夹」「复制文件路径」「复制链接地址」等。

### Agent 插件
- OpenCode 兼容 2.x provider 配置结构（providers.* 与 @opencode/ai/providers/*），按 CLI 主版本自动切换配置写法。
- agent 插件配置、运行时策略与插件注册调整。

## 升级提示
- 桌面端通过内置更新检查获取新版本；Android 通过应用内更新元数据（android-latest.json）增量获取。
